# Computing & Software Engineering Quiz

## Project Description

The Computing & Software Engineering Quiz is a simple web-based quiz application developed to test users' knowledge of computing and software engineering concepts.

The application presents users with multiple-choice questions, allows them to select answers, tracks their scores and displays their final results after completing the quiz.

## Objectives

- To develop a simple and interactive online quiz application.
- To test users' knowledge of computing and software engineering.
- To provide immediate interaction through multiple-choice questions.
- To track and display users' quiz scores.

## Features

- Welcome screen with a Start Quiz button.
- 10 multiple-choice questions.
- Questions covering different computing and software engineering topics.
- Four answer options for each question.
- Question progress tracking.
- Score tracking.
- Final score and percentage display.
- Option to restart the quiz.

## Technologies Used

- **HTML5:** Provides the structure of the application.
- **CSS3:** Handles the design, layout and appearance.
- **JavaScript:** Controls the quiz questions, answer selection, score tracking and results.

## Installation and Setup

No special software installation is required.

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Click the Start Quiz button to begin.

Alternatively, clone the repository using:

```bash
git clone https://github.com/Akramkabir/QuizGame.git
```

## How to Use

1. Open the application in your web browser.
2. Click **Start Quiz**.
3. Read each question carefully.
4. Select an answer from the available options.
5. Continue until all questions have been answered.
6. View your final score and percentage.
7. Click **Restart Quiz** to play again.
